# 吴苑澄观 · 高精度三维苏州园林

以圆明园空间格局（中轴序列、景区分区、借景 / 对景 / 框景）为组织蓝本的江南园林三维场景。几何与 PBR 纹理全部本地程序化生成，零外部资源，构建产物为单个 `scene.bundle.js`。

## 一、运行方式

```bash
# 方式一：直接打开（构建产物是普通 IIFE 脚本，file:// 亦可用）
open wk/002/index.html

# 方式二：本地静态服务（推荐）
cd wk/002 && python3 -m http.server 8080
# 浏览 http://localhost:8080/

# 修改源码后重新构建
cd wk/002 && npm install && npm run build
```

## 三、技术栈

- **Three.js r160 + WebGL2 + 原生 GLSL**，ES 模块经 esbuild 打包为 IIFE 单文件，零运行时外部依赖。
- 自定义着色器：天穹（卷积云、日轮、散射）、水面（Fresnel、波纹法线、岸线裁剪、雨天涟漪）、跌水溪流、草丛渐隐风摆、雨丝、电影调色。
- 后处理 `RenderPass → UnrealBloomPass → OutputPass → GradePass`；ACES Filmic、PCFSoft 阴影、FogExp2 高度雾。
- 静态几何按「材质 + 40 m 空间格 + LOD 细节层」合并；植被、竹、荷、草、林带全部 GPU Instancing；确定性随机种子保证可复现。
- 运行时生成可平铺 PBR 贴图集（颜色 / 法线 / 粗糙度，DataTexture + mipmap + 各向异性）。

## 四、交付要素 1 · 场景规模与 LOD 分级

- 坐标：1 单位 = 1 米；`+X` 东、`−Z` 北、`+Y` 上。尺度锚点：人眼 1.70 m、踏步 0.16 m、栏杆 0.95 m、檐柱径 0.32 m。
- **园林占地**：围墙内 220 m × 190 m = **41,800 m²（4.18 ha / 约 62.7 亩）**；水域 1.32 ha、建筑 0.46 ha、山石园路 0.81 ha、绿化 1.59 ha。
- **场景总尺寸**：**640 m × 560 m**（含园外借景地形、远山林带、北寺塔、天穹）；最高构筑物为园外塔 76 m、园内见山楼 13.8 m、假山主峰 9.6 m。
- **可浏览范围**：漫游 `X ∈ [−150,150]`、`Z ∈ [−140,160]`，视高 0.9–14 m；轨道模式相机距目标 2.5–420 m。围墙内为高精度核心区，园外为借景层。
- **空间组织**：南部 190 m 礼序中轴（照壁→宫门→轿厅→澄观堂→内院→远香堂）；北部一池三山，九个园中园景区。
- 视线关系：借景（园外北寺塔、灵岩山山脊）、对景（远香堂↔雪香云蔚亭、石舫↔见山楼）、框景（延月洞门、漏窗）、障景夹景（照壁、竹径、廊）。

**LOD 分级标准**（距离为「相机 → 对象包围球近缘」，画质档按 1.00 / 0.80 / 0.62 收缩距离带，进出阈值 8% 滞回，4 Hz 判定）：

| 级别 | 触发距离 | 适用范围与内容 |
| --- | --- | --- |
| **L0** 极近景 | 0–18 m | 完整几何：筒瓦垄、瓦当滴水、斗拱、棂条、挂落、砖雕、太湖石涡孔、逐叶草簇；512² 贴图、各向异性 8×、高分辨率阴影 |
| **L1** 近景 | 18–55 m | 保留飞檐、屋脊、棂格、山石主孔与枝干轮廓，剔除微型雕饰；256² 贴图 |
| **L2** 中景 | 55–140 m | 简化体量 + 屋顶剪影，树叶改交叉面片，山石改低模，关闭阴影投射；128² 贴图 |
| **L3** 远景 | > 140 m | 远山、林带、佛塔、村落仅保留剪影 + 高度雾；北寺塔按 0.16 距离权重保留九层中模以维持借景可辨 |

## 六、交付要素 3 · 性能要求与测试条件

**统一测试条件**：Chrome 120+ 无痕窗口、硬件加速开启、WebGL2 ANGLE 后端；本地静态服务 `http://localhost`（零外部资源，禁用缓存做冷启动计时）；
1920 × 1080 CSS 像素 / DPR 1.0（高档另测 DPR 2.0）；固定「全园鸟瞰」与「核心水景」两视角各巡游 60 s；帧率取 60 s 均值与 1% low，帧时用 `EXT_disjoint_timer_query_webgl2` 的 GPU 时长与 CPU 帧时取大值；
加载时间从 `navigationStart` 起算，用 `performance.now()` 在首帧与场景就绪处打点；显存按 `renderer.info.memory` 与纹理 / 几何 / 后处理 RT 估算并用任务管理器交叉验证。

| 指标 | 目标值（高 / 中 / 低） | 测量条件 |
| --- | --- | --- |
| 平均帧率 / 1% low | ≥ 60 / ≥ 45 / ≥ 30 FPS；1% low ≥ 45 / 32 / 24 FPS | 推荐配置 @1080p 高；最低配置 @1366×768 低；60 s 连续无 > 33 ms 长帧 |
| 稳定帧生成时间 | ≤ 16.7 / 22.2 / 33.3 ms | GPU 计时扩展，不可用时回退 CPU 帧时 |
| 渲染分辨率 | 1920×1080 基准，DPR 上限 2.0 / 1.5 / 1.0 | 窗口自适应，4K 屏按档封顶像素比 |
| 首屏可交互 | ≤ 3.0 s（推荐）/ ≤ 5.0 s（最低） | 冷启动、无缓存，至加载页淡出且可接收输入 |
| 完整场景就绪 | ≤ 6.0 s（推荐）/ ≤ 10.0 s（最低） | 至全部纹理、LOD 资源与阴影贴图首次生成完毕 |
| 显存占用 | ≤ 900 / 520 / 300 MB | 1080p，含后处理 RT、阴影 4096²/2048²/1024²、程序化贴图集 |
| JS 堆 / 内存 | ≤ 320 / 240 / 180 MB；进程 RSS ≤ 1.2 GB | 就绪后稳定 5 min 无持续增长 |
| Draw call / 三角形 | ≤ 320 / 260 / 200 call；≤ 1.4M / 1.0M / 0.7M tris | 含阴影 pass，两视角 60 s 内峰值 |
| 网络流量 | 首屏 ≤ 1.6 MB，就绪后 0 请求 | 单文件 bundle，无外部模型 / 贴图 / CDN |

**自检实测**（1600 × 900、无头 SwiftShader 软件光栅，仅用于验证确定性与资源量，不代表真机帧率）：12 个定点视角 + 天气 / 时辰 / 画质 / LOD 切换全部 **0 运行时错误**；
静态合批约 400 组 / 约 40 万三角形（不含实例化植被），draw call 峰值 320（鸟瞰）、其余视角 104–290，含阴影 pass 总三角形 367k–513k，场景就绪约 2.0–2.2 s；LOD 四级在 HUD 中实时计数。

**保底策略**：先压 draw call 再压面数；降级顺序为胶片颗粒 / 辉光 → 像素比 → 草丛与远景林带实例数 → 阴影分辨率 → 近景林木密度，**绝不删除**屋顶轮廓、佛塔、主峰、桥、月洞门等语义核心几何。
自适应降级：连续 2 s 低于 38 FPS 自动降档，回升需 12 s 高于 56 FPS 并设 6–10 s 冷却；任何档位都保留软阴影、水面反射近似、雾与天空。支持 `?q=high|medium|low`、`?lod=1`、`?poi=water` 便于对比测试。

## 八、景观要素与真实感

- **布局与地形**：前朝中轴 + 后苑自然山水；高度场含西北叠石山地（+3.4 m）、东北桂花坡、东南池底下挖（−2.15 m），云墙随地形起伏。
- **建筑**：厅、堂、楼、阁、亭（四角 / 六角 / 扇面）、榭、舫、直廊 / 曲廊 / 爬山廊 / 水廊、九曲桥 / 拱桥 / 廊桥、门楼与园外塔；屋顶为参数化反宇曲面 + 飞檐翘角 + 筒瓦垄 + 脊饰 + 宝顶。
- **假山叠石**：太湖石以 gyroid 等值面涡孔 + 多频噪声皴纹生成，黄石以层理块体拼叠；含主峰群、洞壑、蹬道、峡谷、跌水与特置峰石。
- **水体池岸**：Fresnel 反射、波纹法线、天空 / 远塔倒影近似、岸线柔化、浅水色、雨天涟漪；池岸为自然石矶、条石驳岸与草坡三段。
- **植被花木**：黑松、垂柳、竹、桂、银杏、玉兰、梅、红枫、桃、芭蕉、荷、睡莲、芦苇、书带草、苔与远景林带，按景区主题配置并全部实例化。

- **材质**：运行时生成 PBR 贴图集（颜色 / 法线 / 粗糙度）：白粉墙微裂水渍苔痕、青砖错缝、黛瓦筒瓦垄、栗色漆木、金砖花街铺地、太湖石皴纹、黄石层理、汉白玉、树皮与叶簇。
- **光影与天气**：默认北京时间 15:40 江南午后（西南低角度暖阳 + 冷色天穹补光、4096² 软阴影、ACES、指数高度雾、低阈值辉光、冷暖分离、暗角与胶片颗粒）；时辰 05:30–19:30 连续可调，晴 / 薄霭 / 细雨三态联动云量、雾密度、湿表面与雨丝涟漪，暮色自动点亮廊下宫灯。
