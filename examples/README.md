# Examples

Run npm ci and npm run starter for the offline interactive world. Pick up, place, download, reload and restore without an API key or Docker.

recipes/table.json contains a complete five-part table with explicit colliders and support. Pass the parsed JSON as the asset field of world.addModel in the development SDK. Recipes compile through the asset pipeline; visible geometry does not establish physical capability.

See sdk/typescript/README.md for local SDK tarball installation and CLI scaffolding. The SDK is not published to npm.
