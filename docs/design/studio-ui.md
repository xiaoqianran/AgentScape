# AgentScape Studio UI/UX 设计说明

## 设计范围

本次调整覆盖 Studio 的世界工作台、场景编辑器、生成工作台、资源库与智能体任务页。不重做独立产品首页和 Observatory，也不改变 Runtime、Asset、Generation、Authoring 的事实所有权。

## 从实际界面发现的问题

原入口用纯文字介绍视觉化的 3D 世界，缺少可用于选择场景的预览。产品任务、实现术语和诊断信息混在同一层级；正文与控件普遍偏小；编辑工具在画布底部漂浮。任务尚未开始时就出现多块空执行证据，验收工具又排在常用任务之前。部分错误只能从日志中查找。外层样式存在多轮互相覆盖的布局规则。

此次设计围绕三个问题组织：我正在什么地方、下一步可以做什么、刚才的操作是否成功。

## 信息架构与主要流程

### 世界工作台

优先继续当前可交互世界，或从真实预览中选择示例场景。示例场景、我的草稿、已生成世界分开浏览，数量来自现有资源与存档接口。搜索同时匹配用户看到的中文名称与场景说明。没有结果与没有资源使用不同的空状态，并提供清除搜索、新建草稿或前往生成的实际入口。

新建草稿属于 Authoring 创作流程，不冒充已经验证的 Runtime 世界。没有持久化 ID 的草稿显示“尚未保存”，文件操作错误直接显示在界面中。

### 场景编辑器

桌面采用左侧场景树、中央画布、右侧按需展开的对象属性。撤销、重做、移动和旋转固定在画布上方；保存、导入、导出归入文件菜单。底部只保留当前世界、选择状态与快捷键提示。

属性区区分创作对象与可交互对象，保留对象 ID 作为次级信息。几何关系明确标注为几何推导，不等于动作已经验证成功。输入错误显示在对应面板中，而非仅写入技术日志。

产品页切换保持同一个 3D 画布和运行时；新导航入口同步 URL，避免刷新后落回错误页面。

### 生成工作台

以图片、3D 物体、世界三种输入目标组织界面。默认先准备输入，右侧提供简短流程指引；服务任务与高级设置放在次级入口。结果沿用已有产物栏，不复制生成任务状态。

保留已有的服务连接、输入确认和计算资源费用确认。不会因为视觉调整而绕过上传或远端生成的授权步骤。

### 资源库

内置资源使用实际模型渲染的预览，未知或用户生成的资源没有预览时显示中性图标，不借用其他资源图片。中文显示名称也可用于搜索。

放置完成后选择真实新增对象并进入编辑器。被阻挡、取消、没有生成实例 ID 的结果不会显示为成功。失败时提供可见反馈。

### 智能体任务

常用任务和流程任务优先，开发验收工具折叠。尚无任务时解释如何开始；真正运行后才展示目标、行动、世界变化与验证结果。技术日志按需展开。空指令与不可用服务状态不能提交。

## 视觉规范

沿用项目的石墨色表面与克制的蓝紫强调色，不新增主题或远端字体依赖。主操作突出，次操作使用中性表面；主文案与控件以 12–14px 为主，页面标题 25–30px，技术标识降为次要信息。

五个世界缩略图来自实际内置环境截图，五个物体缩略图来自实际资产渲染，均以 WebP 保存。装饰性 SVG 图标不进入辅助技术的阅读顺序。

共享外壳只管理导航、通用控件与外层几何布局。场景树、资源、属性、生成和任务样式分别由对应功能拥有，避免继续堆叠全局覆盖。

## 响应式规则

1280px 附近压缩次要头部信息。820px 及以下主导航分为第二行，场景树默认折叠并以覆盖层展开，属性面板变为底部浮层。620px 以下世界列表使用单列，生成流程指引不再占用第二栏。资源图保持完整比例，不因容器高度变小而裁掉物体。

编辑器仍以桌面使用为主。窄屏验收检查布局和控件可达性，不代表已经完成实体移动设备的 GPU 性能验收。

## 验证边界

组件契约测试覆盖中文导航、真实预览文件、未知资源回退、不可用的新建入口、可操作空状态、图标可访问性及草稿文件错误反馈。既有控制器和 Runtime 测试保留。

真实浏览器使用独立的本地 Chrome 配置，检查 1440×1000、1280×800、820×1024 和 390×844 四种视口。验证搜索、空状态路由、费用确认、资源放置、属性校验、跨页面画布身份、图片加载和横向溢出；另验证草稿创建、保存、重新打开与设置对话框。

完整仓库检查仍是交付门槛。本轮不调用付费远端生成，不声称完成正式无障碍认证、实体移动设备性能测试或真人可用性研究。
