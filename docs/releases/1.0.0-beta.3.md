# AgentScape 1.0.0-beta.3 发布候选说明

## 主要变化

- Studio 世界库、代码工作台和 AI 任务页采用 Sage Garden 启发的低饱和森系浅色主题；保留 3D 场景自身配色。
- 常驻运行与保存操作、源码编辑区宽度切换、快捷保存与运行、折叠低频功能，保留审批与版本冲突保护。
- MCP 截图拒绝短边小于 32 像素的画布，并在初始化期间有限等待，绑定当前 Runtime，避免将过期画面用于视觉验收。
- 本地代码项目读取不等待共享仓库网络请求。

## 发布范围

三个独立包统一为 1.0.0-beta.3，继续使用 beta 标签。Core 的既有 latest 标签不主动变更。

| 包 | 用途 |
| --- | --- |
| agentscape3d | 轻量语义与动作 Core |
| agentscape3d-engine | 可选 Runtime、物理、资产、Node 与 MCP |
| agentscape3d-studio | 可选 Studio 网站与静态资源 |

## 已完成验证

- 架构、资产、世界可行性、TypeScript 检查通过。
- Vitest：451 个测试文件通过，1 个跳过；2211 项通过、4 项跳过、0 项失败。标准回归不包含实时 Modal 生成用例。
- 三包边界、隔离安装、Studio HTTP、MCP、代码项目、原生 Three.js 挂载、多文件 JS/GLSL 与跨进程恢复通过。
- 森系主题专项浏览器测试：6 项功能测试通过，颜色解析测试修正后单独通过；35 组文字与背景对比度通过。未执行完整 Playwright 套件。
- 生成与资源实验台保留原主题；此前偶发 MCP 会话断开尚未确定根因。
