# AgentScape 1.0.0-beta.2 发布说明

## 主要变化

这一 Beta 版本将原先的综合 SDK 拆为三个独立 npm 发布包：

| 包名 | 用途 |
| --- | --- |
| agentscape3d | 默认核心：自由 Three.js 语义、状态与自定义动作扩展 |
| agentscape3d-engine | 可选 WorldRuntime、物理、资产工具、Node 与 MCP |
| agentscape3d-studio | 可选网站、Studio 与静态资源 |

Core 不接管 Renderer 或 Three.js 动画循环，也不内置任务编译、审批、权限策略和沙箱。MCP 等能力只能通过显式导入的可选包使用。

## 破坏性变更

之前从 agentscape3d 导入 AgentScape.open() 的项目，应改用 agentscape3d-engine。旧的 agentscape3d/node 与 agentscape3d/mcp 路径也迁移到 agentscape3d-engine/node 和 agentscape3d-engine/mcp。

三个包均使用 1.0.0-beta.2 版本与 beta 分发标签。为避免旧版用户无意触发迁移，本次不主动调整已有 agentscape3d latest 标签。

~~~sh
npm install agentscape3d@beta three
npm install agentscape3d-engine@beta three
npm install agentscape3d-studio@beta
~~~

~~~js
import { attach } from 'agentscape3d';

const world = attach(scene);
world.register(door, {
  id: 'door',
  actions: { open: () => { door.rotation.y += 1; } }
});
await world.invoke('door', 'open');
~~~

## 发布前验证

- npm run check：2,081 项通过、4 项跳过、0 项失败；包含架构、类型、构建检查。
- npm run sdk:verify：三个本地 tarball 在隔离临时消费者安装，验证 Studio 静态站点、Engine 物理/资产、MCP、代码项目、原生场景挂载及跨进程恢复。
- npm run sdk:verify:packages：三包内容边界、Core 独立安装通过。
- 从官方 npm Registry 安装 Core 1.0.0-beta.2，在全新消费者执行 Three.js attach 和自定义动作通过。
- 从官方 npm Registry 再次全新安装三个 1.0.0-beta.2 包及 Three.js，执行 Core 自定义动作、Engine 模型创建、Studio HTTP 页面和 MCP 导出烟测，全部通过（退出码 0）。
- Playwright Starter 专项 2 项通过；完整浏览器套件共 55 项在 PC2 的 GLB 物理浏览器用例上出现无断言结果的长时间卡住，不能视为通过。后续应单独排查该用例与 Chromium / SwiftShader / WASM 环境。

## 注意

npm 首次创建新包可能触发自动安全扫描，并暂时只显示 0.0.0-stage。本次 Engine 和 Studio 已通过这项审核，三个目标版本均已从官方 npm Registry 获取验证。发布时保留 Core 的 latest 为旧版 1.0.0-beta.1，三个包的 beta 标签均为 1.0.0-beta.2。

详细迁移指南见 docs/sdk-packages.md。
